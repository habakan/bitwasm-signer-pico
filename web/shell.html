jitsu-in-pico in the browser

The Pico 2 firmware's main.c, review screens and signing core, with parser.wasm running on the same WAMR interpreter, compiled to WebAssembly. Only the LCD, buttons and camera are replaced.

Demo only. Use the test seed. Never scan a real SeedQR here: a browser tab is not a signing device.
Joystick: ←↑↓→, push: Enter. Close: Esc, back or reject. Start with "Use test seed", then "Sign test PSBT". "Scan PSBT" reads an animated QR from the camera.
